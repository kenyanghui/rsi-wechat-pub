# 把财富自由算一遍：10万本金做Wheel策略，滚30年中位数不到56万

> 这不是一篇Wheel教程，而是一次当众数字审计——策略只供给收益率这一个变量，剩下的在工资条和耐心里

刷手机时，你一定见过这类帖子：**「卖期权收租，月月有被动收入」「Wheel策略滚30年，普通人也能财富自由」**。配图是笔直上扬的收益曲线，评论区一片「求带」「蹲一个入门课」。

本文不站队，只做一件事：**把这笔账从头到尾算一遍**。四组数字看完——车速上限、波动残值、残酷情景、应对处方——结论你自己下。

先声明方法与边界：以下所有数字基于历史参数的仿真测算（蒙特卡洛5000条路径×30年），写作时我们已用不同随机种子独立复跑一遍，中位数与各档概率全部吻合复现；但它们依然是测算，不是预言，**不构成任何投资建议**。期权卖方有保证金与接货风险，历史收益假设不保证未来重现。

## 第一算：这台车最快能跑多快？

Wheel策略一句话讲完：**卖出虚值put收权利金→股价跌破行权价就接货→持仓期间卖出虚值call继续收租→货被call走、回到现金，循环重新开始**。像一个车轮不停滚动，所以叫Wheel。

国内能跑的载体是300ETF、50ETF期权。成本结构先看一组数：一张合约名义约**4万元**；卖一张虚值put占用保证金**5000-6000元**；权利金按500元计，佣金就要吃掉约**0.8%**。小合约、高摩擦，这是国内做Wheel的底色。

那么这台车理论上能跑多快？国内做Wheel的长期年化现实带是**8%-15%**（按总资金计），**12%已经是优秀水平**。不是不能赚，是这个收益率的天花板，比多数人想象的低得多。

假设零回撤、每年精准达标，10万滚到500万需要多少年？

|---|---|
| 8% | **50.8年** |
| 10% | **41.0年** |
| 12% | **34.5年** |
| 15% | **28.0年** |
| 20% | **21.5年** |
| 25% | **17.5年** |

连续17年保持25%年化，是巴菲特级别的战绩。多数人以为「15%只是个起点」，而它意味着要做满28年。

**你以为15%是起点，其实它是天花板。**

## 第二算：把波动放进来，还剩多少？

零回撤不存在。真实的30年里一定有坏年份，这笔账要用蒙特卡洛来算：**5000条路径，每条30年**。口径交代清楚：中位年增**9.4%**，年波动**18%**，每年有**15%**的概率挨一次约**-22%**的坏年——相当于六七年遇上一次2022年4月那种级别的行情。

5000条路径跑完，30年后的终点不是一个数字，而是一张分布图：

- 终值中位数：**55.6万**
- 站上100万的概率：**29.7%**
- 站上300万的概率：**6.0%**
- 站上500万的概率：**2.0%**——而且这2%的赢家，中位数也等到**第28年**才到站

![图2 · 蒙特卡洛5000路径×30年：终值分布要点](imgs/fig2_mc_distribution.png)

（模型边界必须交代：9.4%/18%/15%-22%这组参数是简化设定，真实市场的波动结构、坏年频率和执行摩擦都比它复杂得多；上面所有概率只是情景演示，供理解量级用，不是给你对号入座的预测。）

比低概率更扎心的，是「税」。你看到的是账面12%，真实到手的复利要交两道税：

**第一道，波动税。** 涨得深不如跌得浅：-20%之后需要+25%才能回本，上上下下一来一回，12%的账面收益被磨掉约**1.6个百分点**。这笔税是波动率在收，只要你在场内就躲不掉。

**第二道，坏年期望税。** 15%的概率乘以-22%的冲击，在期望值上每年再磨掉**3个多百分点**。这笔税是市场状态在收，频率比强度更致命。

两道税交完，30年长期复利的等价年化只剩约**5.9%**。这就是「账面12%」和「到手5.9%」之间的距离——不是策略骗你，是数学在收税。

## 第三算：换个更残酷的世界，它扛得住吗？

一定会有人说：你的模型太温和了。好，那就把世界调得更残酷，看结论动不动。

**第一组：肥尾世界。** 把正态分布换成t分布，让极端行情出现得更频繁——终值中位**54.9万**，几乎没动。这说明决定30年复利结果的，是中位增速和坏年频率，不是曲线光不光滑。

**第二组：坏年加重世界。** 坏年概率提到**25%**、冲击加深到**-35%**——终值中位直接掉到**11.0万**，站上500万的概率只剩**0.1%**，几乎归零。

![图3 · 三情景对比：坏年参数小幅恶化，结果断崖式恶化](imgs/fig3_scenarios.png)

如果你怀疑真实市场比模型更残酷，你是对的。这两组测试不是在为策略辩护，恰恰是提醒：**坏年参数小幅恶化，结果会断崖式恶化**。Wheel不是无风险的收租机，它对市场状态的依赖，远比晒单帖愿意承认的深。

最后算本金门槛。12%年化下，10万本金一年赚**1.2万**，摊到每个月一千块出头，不到城镇人均可支配收入（约**5.4万**）的四分之一。从10万滚到30万，靠策略自己滚，要**近十年**——而把10万滚成30万这件事，靠涨工资可能两三年就做到了。收益率是策略给的，本金是自己挣的，两者的获取难度完全不在一个量级。

![图4 · 本金门槛：12%年化下，不同本金的年收益 vs 收入线](imgs/fig4_principal_income.png)

**小资金阶段的Wheel是练手机器，不是翻身机器。**

## 第四算：晒单安检 + 你该怎么办？

### 三道安检，戳穿大多数暴富帖

**安检一：幸存者偏差。** 前面算过，30年站上100万的路径不到三成。你刷到的每一张收益截图，都是分布右尾的幸存样本；死掉的、平庸的那几千条路径，从来不会发帖。晒单筛掉的不是失败案例，是整个分布的主体。

**安检二：口径魔术。** 三个问题足够戳穿：起算点选在哪一天——是不是恰好压在低点？有没有加杠杆——收益率是按保证金算还是按总资金算？有没有完整走完接货段——很多晒单只晒收租，从不晒接货扛套的那半年。

**安检三：动机盘问。** 问一句：他的变现端是什么？多数期权晒单的终点是课程、社群、开户返佣——你以为是他的战绩，其实是他的获客成本。证据只认一样：**有时间戳的券商对账单**，其余一律按广告处理。

### 分阶段处方：两种人，两种活法

**如果你是年轻人**——本金小、时间多、还有工资现金流：别跟收益率较劲。把本金从10万做到50万，比把年化从12%提到20%可行得多。算一笔账：**10万年化12%，每年再从工资里追加5万，七年后约72万**。30岁前用最小合约单位把四个环节的坑各踩一遍——卖put、接货、卖call、被收走——几百块学费足够买齐全套经验。

**如果你是中年人**——本金大、但回撤修复时间少：把Wheel当防守收益结构，不是进攻武器。总仓位（含接货敞口）压在可投资产的**三成以下**。中年人真正的风险从来不是错过行情，而是一次40%的回撤之后，没有时间修复。

（处方边界：仓位建议是一般性风控常识，不是针对任何个人的个性化建议；期权是杠杆衍生品，新手先模拟盘、再小仓位，任何人都不例外。）

### 同一个梦想，另一条工位

同一时间线上还有另一群人。上个月，有人用AI Agent在预测平台Polymarket上做**15分钟窗口**的微套利，**29000次**交易赚了**49.3万美元**——注意，这是个案示例，不代表平均水平；此类套利窗口会被竞争迅速关闭，且平台在境外、有合规风险，此处仅作机制说明。

同样冲着财富自由去：一条路是自己下场做策略，本文已经算完，数学不允许幻想；另一条路是让AI当执行员。但执行侧的纪律完全一样——**「堆100个工具，不如跑通1条管线」**。有位Agent实践者用8730条标题库、46天零断更跑出了结果，靠的不是工具数量，是闭环次数。AI放大的是执行力，不是收益率上限。普通人真正的解法，和Wheel的结论同构：**先解决本金变量，让AI把你的单位时间变得更值钱，而不是替你跳过复利公式。**

## 账算完了

回到公式本身：**财富自由 = 本金 × (1 + 收益率)^n**。

Wheel只能供给收益率这一个变量，而且有明确上限；另外两个变量——本金和年数——一个在你的工资条里，一个在你的耐心里。策略不欠你财富自由，它只欠你一个诚实的期望值。

可以做Wheel，把它当成一台转速不高的旧车：**Wheel给不了你财富自由，但它能在你变富的路上，负责不拖后腿。**

### 一、晒单安检自查表（逐条打勾，三条不过直接划走）

**安检一：幸存者偏差**

- [ ] 问自己：这张截图是「某一天的结果」还是「完整30年的路径」？日频截图证明不了长期复利
- [ ] 反事实自查：同策略、同参数，30年站上100万的路径不到三成——发帖的人是右尾，你看到的是被筛过的样本
- [ ] 找样本量：他晒过几次？只有一次高光、从不晒回撤期，按幸存样本处理

**安检二：口径魔术（三问）**

- [ ] 第一问：起算点是哪一天？起算日压在低点的曲线，前两年都是「免费涨幅」
- [ ] 第二问：有没有杠杆？收益率按保证金算还是按总资金算？两个口径可以差出一个数量级
- [ ] 第三问：有没有完整接货段？只晒收租、不晒接货扛套的，策略链路不完整，数据不可信

**安检三：动机盘问**

- [ ] 查变现端：他的收入来自策略本身，还是来自课程、社群、开户返佣？
- [ ] 只认一种证据：**有时间戳的券商对账单**。聊天记录、模拟盘截图、收益曲线图一律不算
- [ ] 终极一问：如果策略真有12%以上年化，他为什么不闷声滚自己的4万一张的合约，而要花时间带你？

三条安检的判定规则很简单：**任何一条不通过，直接划走，不争论**。你的时间比他的课程值钱。

### 三、波动税计算器：Excel三行复算

你不需要任何编程，三行公式就能亲手验一遍「账面12%怎么变成到手5.9%」：

- **第1行·波动拖累税**：`=账面收益率 - 0.5*波动率^2`，代入 `=12% - 0.5*(18%)^2` → 约 **10.4%**（第一道税磨掉约1.6个百分点）
- **第2行·坏年期望税**：`=坏年概率*坏年冲击`，代入 `=15%*(-22%)` → 约 **-3.3%**（第二道税，注意两道税不能简单相加减，复利是乘法世界）
- **第3行·等价年化（中位终值反推）**：`=(中位终值/本金)^(1/年数)-1`，代入 `=(55.6/10)^(1/30)-1` → 约 **5.9%**——这才是30年后落在分布中位时，你真正兑现的年复利

做压力测试就改第1、2行的格子：把波动率改成25%、坏年冲击改成-35%，税额立刻放大；终值会掉到哪？正文第三算的**11.0万**中位就是答案。这个计算器建议每次刷到高收益晒单时跑一遍。

### 四、四条底线（建议打印）

1. **只做现金流富余的钱**：生活备用金、保险、短期要用的钱，一分不进场；卖方保证金之外永远留余量
2. **仓位红线不商量**：年轻人最小单位起步；中年人含接货敞口不超过可投资产三成；红线被击穿的第一动作是减仓，不是补仓
3. **先模拟再实盘**：任何策略（包括本文所有测算对应的操作）未经至少一个完整季度模拟验证，不投真钱
4. **记录每一次决策**：时间戳、口径、完整链路（含接货段）——将来能救你的只有你自己的对账单，不是别人的晒单图
