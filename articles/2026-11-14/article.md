# 41.3k星！Anthropic 把华尔街分析师的 SOP 开源了：拆完这套金融套件，我看到普通人的「一人投研部」

先讲一个反差。

在华尔街，一名投行分析师真正的看家本事，从来不是智商，而是 SOP（Standard Operating Procedure，标准作业程序）：怎么拉可比公司、怎么搭估值模型、怎么把一场电话会拆成模型更新点、怎么写成一份能上投委会的备忘录。这套流程以内部模板和检查清单的形式锁在机构内网里，外面再裹上数十万美元一年的数据终端与百万年薪的人力成本——这是普通人与专业机构之间真正的差距。

2026 年 11 月，这道墙裂开了一道缝：Anthropic 在 GitHub 上开源了金融服务 AI 套件（仓库 `anthropics/financial-services`，完整地址：https://github.com/anthropics/financial-services）。截至 2026 年 11 月 14 日 GitHub 页面实测，Star 数达 41,277（发布当日较素材报道时的 17,500 已翻倍还多，热度仍在爬升），采用 Apache 2.0 许可证；投资银行、股票研究、私募股权、财富管理四大业务线的 Agent 参考实现，全部免费可取。

把这些「最贵的工作流」打包放出来的，是一堆 Markdown 文件。

本文做三件事：拆开看它的三层结构（拆）；讲清为什么这样分层（懂）；给出普通人复刻的最小可行路径（抄）。结论先放在这里——它不是工具清单，而是把锁在机构内部多年的行业方法论，做成了可安装、可审计的文件。

## 一、拆：三层结构——10 个 Agent、7 类技能包、11 家数据商

据该套件 README，整个仓库的组织可以概括为三层：Agent 层、垂直技能包层、数据连接器层。

**第一层：10 个端到端 Agent。**覆盖金融业务里最标准化的十类场景：

- Pitch Agent（路演材料）
- Meeting Prep（会议准备）
- Market Researcher（市场研究）
- Earnings Reviewer（财报点评）
- Model Builder（建模）
- Valuation Reviewer（估值复核）
- GL Reconciler（总账核对，GL 即 General Ledger 总账）
- Month-End Closer（月末结账）
- Statement Auditor（报表审计）
- KYC Screener（客户身份核查，KYC 即 Know Your Customer）

每一个都是 self-contained（自包含）的：skills、工作流、执行方式打包在一起，装上就能跑完一个端到端任务。

以最值得个人投资者研究的 Earnings Reviewer 为例，它的完整链路是：读取财报与电话会记录 → 更新财务模型 → 生成研报草稿。配合核心插件 financial-analysis 的模型能力——可比公司分析（comps，Comparable Companies Analysis）、现金流折现（DCF，Discounted Cash Flow）、杠杆收购（LBO，Leveraged Buyout）与三表联动模型——再以斜杠命令调用：`/earnings` 处理财报、`/comps` 拉可比、`/dcf` 算估值、`/ic-memo` 生成投委会备忘录（IC 即 Investment Committee 投资委员会）。从「一家公司发了财报」到「一份带估值分析的初稿」，中间所有机械环节被压缩成一条命令。

**第二层：7 类垂直技能包。**按业务线划分：

- financial-analysis（金融分析）
- investment-banking（投资银行）
- equity-research（股票研究）
- private-equity（私募股权）
- wealth-management（财富管理）
- fund-admin（基金行政）
- operations（运营）

技能包以 Markdown 与 JSON 文件存在，本质是把领域知识写成文本：行业术语、分析框架、输出规范。改几个术语、换一套模板，就是定制版——门槛低到不像「改代码」，更像「改文档」。

**第三层：11 家数据商连接器。**据 README，套件通过 MCP（Model Context Protocol，模型上下文协议）接入 Daloopa、Morningstar（晨星）、S&P Global（标普全球）、FactSet、Moody's（穆迪）、MT Newswires、Aiera、LSEG、PitchBook 等 11 家金融数据商。这一层解决的是「数据从哪来、能否追溯」——机构级工作流的地基从来不是模型，而是带权限、带审计的数据管道。

三层之外，有一条边界必须原样转述。README 免责声明写明：Agent 产出是「分析师草稿」，需合格专业人员审核；不提供投资建议、不执行交易；所有输出暂存，等待人工确认。一套以自动化为卖点的套件，把「人工确认」写成默认流程——这个细节，比 41.3k 星本身更值得琢磨。

## 二、懂：为什么偏偏是这三层

看懂分层逻辑，比背下清单重要。

**Agent 层承载完整工作流。**端到端 Agent 的价值不在单点能力，而在动作序列：先查什么、再算什么、按什么规范输出、在哪里停下来等人确认。这与量化投资的方法论同构——SOP 化，把判断流程规则化，让每一步可复现、可检查；也呼应量化里「先想怎么死」的纪律：流程必须写清在哪里退出、在哪里停手。

**技能包层沉淀领域知识。**工作流解决「按什么顺序做」，技能包解决「按什么标准做」。国内已有的单 Skill 拆解验证了这个颗粒度：季报点评类 Skill 把「读电话会 → 提取指引 → 更新模型 → 出点评」拆成带检查点的步骤；组合管理类 Skill 内置结构化的「组合体检」清单；估值复核类 Skill 干脆把「机器算、人拍板」写进流程本身——机器负责算数，人在关键节点签字。

**连接器层解决数据权限与可审计。**模型再强，喂错数据就输出错结论。MCP 连接器把数据来源显式化，每个数字都能追到数据商——这是机构级与玩具级的分水岭。

把三层合起来，就能读懂那句核心论断（据相关拆解文章）：「AI Agent 的竞争，开始从模型能力进入行业工作流阶段」「未来最值钱的不是 prompt，而是被 AI 重写过的行业工作流」。模型能力各家都有，工作流才是壁垒。Anthropic 开源的意图也在此：模型是引擎，工作流是整车——把车送出去，是为了让引擎有地方跑。

## 三、抄：一人投研部的五步最小可行版

官方给了三条部署路径：个人侧走 Cowork 或 Claude Code，企业侧走 Managed Agents API（Application Programming Interface，应用程序接口），另有 Microsoft 365 集成。个人复刻对应第一条路径，具体五步：

**第一步，只选一条业务线。**四大业务线中，建议从股票研究（equity-research）起步：公开数据可得性最好，个人验证闭环最短。一个人养不起七条业务线，正如一个散户读不完所有行业。

**第二步，数据层用免费源替代付费连接器。**11 家数据商的 MCP 连接器是机构方案，个人不必付费接入。开源数据方案（如 AKShare 类聚合库）已覆盖行情与财报基础数据；个人侧实现也已被验证——有开发者做了「金融圈版 Claude Code」，跑通「查财报 → 写分析」的自动化链路；也有人基于 OpenClaw 搭建个人投研助手并给出 4 个实战案例。数据不构成门槛。

**第三步，把 SOP 落成自己的 skill 文件。**抄结构，不抄结论。把 Earnings Reviewer 的链路改写成自己的版本：我的财报阅读顺序、我的模型更新检查点、我的研报模板。已有实践者把「一句话生成研报级财经分析」做成自制开源 skill——证明这条路一个人写一个文件就能起步。

**第四步，强制人工确认，外置风控。**这是五步里最重的一步。反面教材已经存在：据 arXiv:2609.19705（《Trading Agents or Market Crashers?》）的审计样本，对 FARSIGHT 系统的 15 套 AI 自动交易方案测试中，12 套得分接近零分，占比约 80%；7 份可运行代码里，0 份内置外置止损。结论直白：去人化的 AI 金融流程，缺的不是能力，是风控。所以个人版本必须保留两个动作——AI 只出草稿，关键数字人工核对；止损纪律放在 AI 之外，用条件单或硬规则执行，不托付给模型的「判断」。再补一道「回测验证」：任何流程先过历史回测再谈实盘——未经验证就直接上真金白银，等于把 FARSIGHT 的教训重演一遍。

**第五步，把研究产出当「假设」，不当「答案」。**AI 生成的草稿，性质是一组待验证假设：数据要抽查、逻辑要过一遍、结论要找反例。决策权与责任，始终在人。

五步走完，你就有一个最小可行的「一人投研部」：一个人、一排 Agent、一条强制人工确认的流程。它不承诺任何收益，它给的是研究效率的结构化提升，与每个结论的可追溯。

## 四、收束：最值得沉淀的资产，是被你重写过的 SOP

回到开头。彭博终端数十万美元一年的订阅、投行分析师百万年薪背后沉淀的工作流，如今以 41.3k 星的形态躺在 GitHub 上。开源的意义从来不是「免费拿走」，而是看清结构之后，长出自己的版本。

这套套件给出的行业信号很明确：竞争正在从「谁的模型强」转向「谁的工作流被 AI 重写得更好」。对个人，对应动作只有一个——别再囤 prompt（提示词），去沉淀你自己的 SOP：你的研究流程、检查清单、止损规则。prompt 会过期，被 AI 重写过的行业工作流不会；它可积累、可复利、可迁移，是普通人在 AI 时代门槛最低的工程化路径之一。「财富自由」说得太远，但研究能力的机构化平权已经发生——这是路径，不是承诺。

最后借财联社一句话作结：工具平权不等于收益平权。工具人人可用，结果各自承担。
