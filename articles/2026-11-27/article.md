# AI 会复盘，为什么还是原地踏步？复盘的进化单位，是「证据」而不是「感受」

> 单次经历只是噪音样本：从 MGM 的跨血统进化，到普通人能跑起来的失败证据库

# 一、复盘了三周，能力曲线为什么还是平的

先描述一个你大概率经历过的场景：三周前你决定认真复盘。每天下班写日报，每周日写周报，还给 AI 工具设了一个「自动复盘」的定时任务，让它总结你今天的得失。三周过去，你打开自己写下的几万字复盘记录，再看看手上的活儿——遇到同类问题，该踩的坑一个没少踩，判断质量跟三周前几乎没有差别。

复盘了，但没进化。工具越强、复盘越勤，这个悖论就越刺眼：以前没时间复盘还能怪忙，现在 AI 替你把总结都写好了，能力曲线依然是平的。更微妙的是，复盘还带来了额外的心理收益——「我今天认真反思过了」的踏实感。付出感有了，仪式感有了，唯独能力没变。于是复盘从进化工具，慢慢退化成一种精神按摩。

问题出在哪？大多数人会归因于「复盘得不够认真」「总结得不够深刻」，然后加大力度——写更长的复盘、更频繁的复盘。方向恰恰反了。**不是复盘的数量不够，是复盘点选错了：你记录的是「感受」，而进化的最小单位是「证据」。** 感受是一次性的，证据才是可复用的。

这篇文章把这件事讲透：为什么单次经历只是噪音、为什么闭门复盘有天花板、AI 研究圈最近的一个进化实验给出了什么答案，以及一个普通人今天就能跑起来的「证据化复盘」最小清单。全程用量化的视角做镜像——因为量化交易者在这个问题上摔过的跤，比任何行业都多。

# 二、单次经历是噪音，证据才是信号

先补一个量化行业的基础共识，它是全文的地基。

你跑了一个策略回测，年化收益很漂亮，这个数字能说明什么？什么都说明不了。它是随机变量的一次采样：同样的策略逻辑，换一段行情、换一个起点，结果可能完全不同。量化研究员真正看的是**样本外表现**——模型没见过的数据上的成绩，那才接近策略的真实水平。把样本内的漂亮数字当成规律，是这个行业里最经典、也最昂贵的死法。

行业里成熟的团队会把这条纪律写进协议，而不是留在口头：回测必须纳入成本、必须做样本外校正，任何没有经过样本外检验的结论都不允许进入实盘。这不是某家机构的秘技，是整个行业用真金白银换来的公共知识。

把这个镜像搬到个人复盘上，问题立刻显形：**一次失败的经历，就是一次采样。** 项目黄了，你总结「下次要多沟通」；方案被毙，你总结「下次早点对齐」。这些结论全部产生于样本内——就这一次经历，你却把它们写成了规律。下一次场景稍变，「多沟通」可能恰恰是错的。

更麻烦的是，单次经历自带一种「必然如此」的错觉。事后看，因果链条顺得像是排好的剧本——这叫事后归因偏差：结果已经发生，你的大脑会自动把链条上的偶然环节补成必然。回测里的样本内过拟合，和复盘里的事后归因，是同一个认知缺陷在两个领域的名字。样本量为一的时候，你看到的不是规律，是命运剧场里的一场独演。

感受是采样时的情绪波动，证据是去噪之后的结构。单次经历本身不构成进化原料，**可跨任务、跨场景复用的失败结构才构成**。这就是「复盘了却没进化」的第一层原因：你把噪音存了盘，信号反而没留下。

判断你写下的复盘是感受还是证据，有个粗暴的检验标准：把时间、地点、人名全部隐去，这条记录还能指导一个陌生人在同类情境下行动吗？「今天和客户开会很受挫，我要提升沟通能力」——隐去之后什么都不剩，这是感受。「客户在报价环节第三次提出分期时流失，猜测对总价敏感度高于对首付压力，置信度低，需十次以上同类样本验证」——隐去之后依然是一条可执行的待验证规则，这才靠近证据。

# 三、「闭门复盘」的天花板：只看自己这一次

即便你意识到了这个问题，开始把复盘写得结构化，还有第二层天花板等着：**你只有自己的样本。**

AI 研究圈正好在做同一件事，而且把问题暴露得更彻底。近年有一条「自进化 Agent」的技术路线——Darwin Gödel Machine（DGM）和它的前代 HGM 是代表：给一个能写代码的 Agent 一个任务，让它发现问题、修改自己的 scaffold（脚手架代码），跑评测，保留更好的版本，循环往复。听起来很美：机器自己复盘自己，越改越强。

但研究者很快发现这条路线的盲区：**它只看自己的失败。** Agent 在某个任务上得分不佳，反思一下，改一版，再测。问题在于，这次失败到底暴露了什么？是架构问题、流程问题，还是评测太随机？只盯着自己这一次的成败去猜，跟一个人闭门复盘三年、结论全是「我要更努力」差不多——归因的自由度太大，猜错的概率极高。

人类这边是同构的。只看自己的失败，你只能在自己的经验范围内猜原因：同事不配合、时机不好、自己不够拼。你缺的是对照组——**别人在同一道题上是怎么失败的，以及你自己这件事在别的场景里是不是也失败。** 没有横向样本，复盘就退化为自我叙述；自我叙述写一万字，进化单位还是零。

闭门复盘的天花板，本质是样本量的天花板。一个人的一生，撑不起一个可靠的结论。

# 四、MGM 的答案：比较、遗传、跨血统迁移

今年，电子科技大学、LMU Munich 与 MCML 的研究者提出了 Mendel Gödel Machine（MGM），名字直接取自遗传学之父孟德尔——因为它的核心动作就是「杂交」。这个命名不是修辞，是对机制的精确概括：孟德尔之前，生物学家盯着单个个体的性状猜遗传规律，猜了几百年收获寥寥；孟德尔把视角换成「群体中性状如何传递、杂交后什么被保留」，遗传学才真正成立。MGM 做的是同一件事：把 Agent 进化从「盯着自己改」换成「在种群里杂交」。

它对上述盲区的解法可以压缩成一句话：**别只看自己这一次怎么失败，去看两样东西——自己在别的任务上怎么失败，别人在同一道题上怎么做。**

具体机制上，MGM 维护一个 Agent 种群：不同「血统」的 Agent 各自带着自己的 scaffold 变体。某个 Agent 在任务上失败时，它不是独自反思，而是去检索种群里的成功案例——其他血统的 Agent 在同一道题上用了什么工作流、什么工具组合；同时参照自己在其他任务上的失败模式，把「这里失败」和「那里成功」做交叉比对，把有效的结构**遗传**给下一代。失败不再是孤立的疼，而是可交叉引用的数据点。

数字摆出来最有说服力：同样的 Qwen3.6-35B-A3B 底层模型、相同的 evaluation 与 expansion 预算（算力条件完全对齐），在 Polyglot-60 基准上，传统自进化路线 HGM 从 50.8% 提升到 77.9%，而 MGM 做到了 93.2%。**底层模型一个字没变，差距全部发生在 scaffold 和工作流层。** 同样的算力，喂养方式不同，进化速度差出一大截——多出来的那一段，就是「跨血统学习」带来的。

这里有个值得停下来看一秒的细节：改进没有发生在模型权重里，而是发生在「怎么组织工作」的流程层。对 Agent 来说，scaffold 是大脑外面的那套工作方法；对人来说，对应的就是流程、清单、检查项、协作方式这些可改的东西。这对普通人是个好消息——意味着你不需要换一个更聪明的大脑，只需要改进复盘信息的来源结构和复用方式；瓶颈不在天赋层，在方法层。

把 MGM 翻译成个人语言，复盘的输入端从此多了一个方程：**你的失败 + 你的其他失败 + 别人的同类失败 + 别人的同类成功，四项交叉比对之后，留下的才配叫证据。** 只有两项的版本（只有自己、只有这一次），噪音太大，不构成进化原料。

# 五、给人类装 H-Skill：把判断规则写成协议

输入端解决「证据从哪来」，还差一半；另一半是输出端——证据存下来之后，以什么形态存在，才能在下次被真正调用。

量化圈有个现成答案：协议化。最近「Human Skill」的思路被明确提了出来：参照 Agent 的 Skill 机制，给人类大脑也装一个「临时操作系统」——把反复使用的方法、流程、判断规则，整理成结构化、可随时加载调用的协议，而不是散落在笔记和记忆里的「读过」。

一家 CTA 量化团队公开过他们的研究员 H-Skill 里最核心的几条协议，每一条都是血泪的结晶。所谓 H-Skill，就是参照 Agent 的 Skill 机制给人类设计的同类物：Agent 需要时加载一段 Skill 就能临时获得一套工作方法，人也需要在关键场景加载一套预整理的判断规则，而不是临时靠记忆和直觉硬拉。随便摘几条感受一下密度：

- **先写假设，再跑验证**——防止数据窥探：先看数据再找规律，你找到的几乎必然是过拟合的噪音；
- **风险优先于收益**——先确定最坏情况亏多少、能不能活着，再谈赚多少；
- **实盘与回测的偏差本身就是信息**——偏差指向你模型没覆盖的真实世界结构，它是免费的情报，不是麻烦；
- **不追圣杯，追可重复的微小优势**——伟大策略不存在，可重复执行的小优势复利起来才存在。

注意这些条目的形态：不是感悟，不是金句，而是**带触发条件和执行动作的规则**。遇到什么情况、按什么步骤处理、禁止做什么，写得像代码一样可以照着跑。

为什么规则必须外化成协议，而不能靠「记住了」？因为人在压力下的记忆和判断都不可靠。交易员盯盘时心跳加速、认知带宽收窄，平时烂熟的纪律此刻就是会掉线——所以成熟团队把纪律写成墙上贴着、系统强制的硬规则，而不是放在脑子里。复盘结论也一样：它恰恰产自你状态最好的时候，却要服务你状态最差的时候。状态差的时候能被可靠调用的，只有白纸黑字的协议。

这就是复盘产出和「读过」的分水岭：复盘写完，如果只是「读起来有道理」，它会在三天内蒸发；如果被压缩成协议条目，写进你的工作流程里，每次遇到触发条件自动加载——它才成为你的操作系统的一部分。**复盘的目标不是「写过」，是「可加载」。**

# 六、失败证据库：你交的学费能不能变成别人的数据集

协议化解决「存成什么形态」，接着解决「存给谁用」。这里要引入一个财富观层面的视角。

在一期访谈里，学者方言说过一句很锋利的话：**普通人是通过「消灭财富」的方式来「彰显财富」的。** 买了超出驾驭能力的东西，钱消失了，只留下一件贬值的车、一套供不起的房——他称之为「丢失这笔钱的发票」。而真正的财富是驾驭资本的能力，那种能力只能从「交学费」里长出来：钱亏掉了，但如果驾驭能力的级别升上去了，学费就交得值；钱亏掉了、能力原地踏步，那就是纯粹的消灭。

（方言的访谈属个人经验分享与观点表达，非普遍规律，更不构成任何操作建议——这里只取其框架。）

把这个框架接到复盘上：你亏掉的钱、搞砸的项目、错过的机会，都是已支付、不可退的学费。学费的去向只有两个——变成你的能力，或者凭空消灭。注意这个框架不限于金钱：跳槽跳错的公司、跟错的方向、押错的技术栈，都是广义的学费，同样的二分法全部适用。分界线就是那个老问题：**你有没有把这次失败写成结构化证据。**

一条合格的失败证据长这样：**触发条件**（什么情境下）、**预期**（当时以为会发生什么）、**实际**（真实发生了什么）、**归因**（差距来自哪个环节，且注明归因的置信度）、**适用边界**（这条结论在什么范围内成立、什么场景下不适用）。

五字段写全，这条失败就从「你的疼痛」升级为「数据集里的一行」：下次你自己遇到同类情境，可以检索调用；将来分享出去，它就是别人数据集里的一行。注意「适用边界」字段的分量：它把这条证据限定在验证过的范围内，防止下次被过度外推——量化行业里最贵的错误从来不是没有结论，而是结论用错了边界。这也是开头那句话的完整含义——**你的失败是别人的学费，别人的失败是你的数据集。** 闭门复盘浪费的从来不只是自己的样本，还有整个群体本可以共享的样本池。

# 七、量化镜像：风控事故都是「证据复用失败」的案例

有人会质疑：把失败写成五字段的一行数据，真有那么大威力？看一个刚刚发生的、代价约四百万美元的反例。

去中心化衍生品平台 Hyperliquid 上，一位巨鲸用 1523 万 USDC 保证金开设了 16 万 ETH 的多头头寸，名义价值约 3.07 亿美元，杠杆约 13.5 到 19.2 倍。浮盈后，他从关联账户提取了 1709 万 USDC，大幅降低保证金率——头寸进入「清算成本极低」的脆弱状态。随后价格小幅回落触发清算，精明资金立刻围绕这次清算做套利，平台官方金库 HLP Vault 被动承接了敞口，损失约 400 万美元——约占其 TVL 的 1%，相当于它此前历史利润的 6.6%。整条路径环环相扣：加杠杆建仓、浮盈抽走保证金、等一个小幅回撤、清算程序按规则执行、套利资金顺规则收割。每一步单独看都合规，合起来就是一次精准的机制套利。

事后复盘这个案例，最刺眼的不是损失本身，而是：**这个攻击机制早就被公开讨论过**——低保证金头寸可以被人为做成清算诱饵，吸引套利资金挤压做市方，逻辑链条行业里写过得一清二楚。缺的不是知识，是把「同类机制的攻击面」作为一条证据正式入库：触发条件是什么、传导路径是什么、我们暴露在哪个环节、边界条件是什么。没人写，没人加载，于是同一类机制换个标的再次上演时，四百万美元替所有人重新交了一遍学费。这就是「感受式复盘」和「证据化复盘」在机构层面的分野：前者会在事后写一篇情绪浓烈的检讨，后者会在事前留一张可检索的攻击面清单。

平台的事后动作恰好是教科书级的回应：下调杠杆上限，BTC 降到 40x，ETH 降到 25x。制度不会反思，但制度可以被「复盘改协议」——把一次事故固化成一条新规则，这正是本文主张的全部动作。

（再次强调：此处仅作风控机制分析，为个案事件复盘，不构成对任何交易平台、代币或策略的评价与推荐，更非投资建议。）

# 八、最小可运行版：个人复盘的证据化清单

理论到齐了，现在给一个今天就能跑的最小实现。它由三个动作组成，分别对应前面的三层：证据的结构、证据的来源、证据的去向。

**动作一：单条证据五字段。** 每次失败（或显著意外），强制写五个字段：触发条件 / 预期 / 实际 / 归因（附置信度：高、中、还是猜的）/ 适用边界。写不完五字段，宁可先不写结论——半条证据好过一条错误的规律。「归因」一栏诚实标注「这只是猜测」的情况要占多数，这不是敷衍，这是统计学上的诚实。

**动作二：跨源比对，凑齐四个样本。** 写完单条，做两次检索：一次检索**自己**的证据库里有没有同类触发条件的历史记录（自己的这一次 + 自己的历次）；一次检索**外部**——同事、社区、公开案例里别人怎么处理同类情境（别人的失败 + 别人的成功）。四项交叉比对之后，归因栏才允许从「猜测」升级为「初步结论」，并同步更新置信度。

**动作三：写入协议，完成加载。** 跨源比对确认的证据，压缩成一条带触发条件的协议规则，写进你的「核心协议」文档——那个每次开工前会真的打开、真的过一遍的文档。协议条目定期做减法：连续几次实践证明不适用的，降级或删除。协议是操作系统，不是纪念墙。

这三个动作串起来，就是普通人能碰到的「递归自我改进」的最小实现：失败→结构化→交叉验证→协议更新→下次自动调用→新失败再进入循环。每一圈循环，进化的单位都是一条证据，而不是一段情绪。你没有 MGM 的算力，但你有和它同构的回路——而且你的「种群」成本是零，读别人的复盘、听别人翻车，就是在做跨血统检索。

三个反模式顺带交代，都是常见跑偏：一是**只攒不用**——证据库记了几百条，从不做跨源比对，那只是一个更整齐的日记本；二是**越写越虚**——字段写着写着滑回「要更专注」式的口号，检验办法还是那条：隐去时间地点人名还能指导行动吗；三是**协议不删**——条目只增不减，最终没人看，协议库定期做减法和写新条目同等重要。避开这三个坑，这套最小系统就能一直转下去。

# 九、收束与风险提示

回到开头的悖论：复盘了三周，能力曲线是平的。现在答案完整了——因为进化从来不以「次」为单位，而以「证据」为单位；从来不以「个体」为范围，而以「群体」为范围。

单次经历是噪音，结构化、经交叉验证的证据才是信号；闭门复盘有天花板，跨血统检索才能突破它；证据存成协议才能被加载，存成数据集才能惠及他人。MGM 用同样的算力把基准成绩从 50.8% 推到 93.2%，靠的不是更聪明的模型，而是更聪明的样本使用方式——这件事对个人同样成立，甚至更成立，因为你缺的从来不是算力，是复盘的物理结构。

从今天起，把复盘清单从「今天学到了什么」换成三个问题：这条经历的**触发条件**是什么？**别人的样本**里它成立吗？**协议库**要更新哪一条？三个问题都能答上来，这一天才真正进入了复利账户；答不上来，写再多字也只是又一次精神按摩。进化这件事，从来没有 shortcut，只有记账方式的不同。
