先做个测试：打开你存放策略代码的那个文件夹，数一数里面有多少个文件，再数一数有几个现在还能直接复用。

`strategy_v1.py`、`strategy_v2_final.py`、`strategy_v3_真final.py`……每个文件背后都是当时的一个灵感：一组均线参数、一个因子组合、一次盘后复盘的冲动。写的时候热血沸腾，跑完回测存进文件夹，三个月后再打开，连自己都看不懂当时的逻辑，更别说接着用。

这就是「策略月抛」：像隐形眼镜一样，用一次扔一次。大多数人做量化研究的真实状态，是用最高的频率生产一次性消耗品——每年写几十个策略，没有一个真正留下来。

开源量化框架 QuantSpace 的作者在文档里有一句很扎心的话：**量化研究最大的损耗不在策略本身，而在工程的离散**。策略会失效，这很正常；真正致命的是，半年前那段代码如今连作者本人都无法复用——研究没有积累，一切归零重来。

## 一、认知翻转：策略是消耗品，研究资产才是复利载体

这里需要一个认知翻转。

多数人默认，量化研究的产出物就是「策略」：找到一个能赚钱的策略，研究就成功了。但策略天然是消耗品——市场风格一变、参数一漂移，它就失效，然后被月抛。

那什么不是消耗品？**研究资产**：干净的数据管道、可复用的因子计算模块、标准化的回测流程、可验证的报告模板、清晰的项目结构。这些东西不会因为某个策略失效而过期，反而随着一次次研究被反复打磨、越来越锋利——这才是复利的载体。

机构真正的壁垒，从来不是某一个策略，而是这条研究流水线本身。策略只是流水线上流过的水，管道才是资产。

「产出不等于资产」，机构研究里同样有硬数据。东吴金工在一篇 AI 因子挖掘实践中给出过一组对照：AI 一次能产出 87 个候选因子、平均增量 IC 约 2.53%——产出能力不可谓不强，但如果这些产出不沉淀下来，就只是消耗品，下个项目还得从零再来。个人研究者更是如此：你在数据和算力上拼不过机构，唯一能拼的，是让同样的时间产生可以留下来的东西。

## 二、QuantSpace：把研究资产化的完整实证

说机制容易，难的是落地。这正是 QuantSpace 的价值：它不是一篇概念文章，而是一套完整跑通的工程实证。

作者在干净环境里做了全链路实跑——从安装、跑 demo、生成报告到跑测试，每一步都有真实执行的终端输出与自动渲染的报告，不是 README 截图党。几个关键设计值得逐个看：

**八个公开 skill 串成固定数据回路**：ingest→store→compute→analyze→backtest→ml→research→report。从数据接入、存储、计算、分析、回测、机器学习，到研究记录与报告输出，每一步都是独立、可复用的单元。于是研究不再是「从头写一遍」，而是「在这条回路上走一遍」。

**目录结构本身就是契约**。这是原文里我最喜欢的一句话：数据放在哪、因子怎么命名、报告怎么生成——结构定了，团队协作、AI 接手、半年后的自己回看，都有据可依。研究的可交接性，是从目录结构开始的。

**三行命令开箱即跑**：uv sync 装好环境、生成合成数据、跑横截面与时序 demo。不配置数据商凭据也能先体验完整流程，上手门槛低到几乎为零。

**161 个公开测试，159 通过**，失败的 2 项仅因缺少数据商凭据。工程质量用测试说话——这是「可验证」三个字最直接的形态。

## 三、四份公开示例：真实历史行情上的回测数字

框架自带四份基于真实历史行情的公开示例，区间收益分别是：

- **期货 XGBoost 排序**：2024 年 +18.7%，2025 年 +45.7%
- **期货横截面反转**：+30.8% / +31.4%
- **CSI 300 IF MA10 ATR 反转**：+22.1% / +36.3%
- **CSI 300 IF XGBoost 三重障碍**：+12.9% / +4.9%

这些数字的意义不在高低，而在于它们是**框架自动渲染的绩效产物**：研究做完，报告自动生成、绩效曲线自动绘制，整条链路可复现、可检验。

按照惯例，必须原样给出原文自带的免责表述：**示例区间收益仅供参考，基于历史行情回测，受数据窗口、参数与样本范围影响，不构成收益承诺或投资建议。**

还有一点值得注意：同一框架、同一套流程，不同策略、不同年份，收益从 +45.7% 到 +4.9% 波动巨大。这恰恰印证了前文的判断——策略是消耗品，单次结果说明不了什么；流程与资产，才是长期站得住的东西。

## 四、边界与风控：明确告诉你什么不能做

QuantSpace 对自己的定位写得非常克制：**研究与工程框架，而非自动交易系统，不接券商接口、不执行订单**，是否实盘需结合自身策略与风控独立判断。

这个边界值得展开讲，因为它恰恰是专业性的体现。

研究到实盘之间横着一道「隐形断层」：回测环境与实盘环境在撮合、延迟、滑点、资金约束上完全不同，回测里的漂亮曲线到了实盘常常变形。开源引擎 NautilusTrader 的核心定位就是把量化策略从回测带到实盘，为此它专门选择 Rust 重做底层——用工程手段弥合这道断层，是专业领域的共识，而不是个人项目的额外烦恼。QuantSpace 把自己严格限定在研究侧、不碰执行，反而回避了「回测好看就直接下单」这个最大的风险源。

另一个边界是合规。最近 GitHub 上有个 9800+ 星的项目 craft-anything，默认采用净室模式——只依据外部行为复刻软件，不读取私有源码；此前同类项目 REA 就有用户因触碰私有代码导致账号被封的教训。拆解与复刻有边界，研究资产的沉淀同理：公开数据、公开接口、公开协议，才是能长期积累的底座。

## 五、财富落点：一人量化自营的复利底座

回到「AI 财富」这个常驻话题，先说一句冷静的话：复利的前提从来不是某个惊艳的收益率，而是**可积累性**——今天的投入能成为明天的基础，而不是归零重来。

这个逻辑在量化之外也正在被验证。最近开源的 CLI-Anything（43,937 星）做的事情，是把存量软件封装成 AI 可调用的工具，让 AI 真正操控你电脑上的本地软件——不联网的老软件，一个个变成 AI 能驱动的资产。它和 QuantSpace 做的本质上是同一件事：**把存量能力资产化**。软件如此，研究流程亦然。

对想搭「一人量化自营」的读者来说，复利底座不是某个神奇策略，而是把每一次研究都变成**可运行、可测试、可交接**的资产。QuantSpace 原文给出的五步工作法，可以直接照抄：

1. **说清想法**：先用自然语言把研究问题写清楚；
2. **优先复用 skills**：先查八个 skill 里有没有现成模块；
3. **脚本只做编排**：新写的代码只负责组装，不重复造轮子；
4. **沉淀产物**：数据、因子、报告按契约归档；
5. **交付前验证**：测试跑过再交付。

这个最小动作今天就能开始：建下一个项目的文件夹时，先把目录结构定下来——定好结构，就是定好契约。三个月后回头看，你和半年前的自己之间，终于有了可以接续的东西。
