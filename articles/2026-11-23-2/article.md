# 3万一年的数据接口，现在免费送你一天500次：量化入场券正在大清仓

## 一、先看一个价格：三万元一年

很多普通人不是没想过"量化"这件事。

你在券商软件里看过K线，在论坛里刷过策略帖，甚至可能点开过 Python 入门教程，装过 Anaconda，跑通过一个画K线的脚本。但绝大多数人在"用程序做投资"这条路上只走了半步就停下了。停下的原因往往不是不想学，也不是学不会，而是一笔算不过来的账：做量化研究，数据从哪里来？

量化研究的第一步永远是数据——日线、分钟线、财务报表、指数成分、公告文本、北向流向。要让程序理解市场，先要让程序拿到数据；拿不到数据，后面所有的模型、因子、回测，都只是纸上谈兵。而在国内相当长的时间里，获取这些数据的接口一直是要花钱的，而且收得不便宜。

EarlETF 主理人张翼轸在《ETF+AI+Agent，普通人的量化投资拼图凑齐了？》一文中给出的行情价是：数据 API 一年 3 万元起步，金融数据终端另算。

三万元一年，是什么概念？

对一家机构来说，这是预算表里不起眼的一行小字，摊到研究员头上每人每月两千多，属于"不用讨论的常规开支"；对一个拿工资的散户来说，这是在验证任何想法之前就要先付出去的沉没成本——你还没有证明自己的策略值得研究，先要预付一笔可能永远收不回的开销。如果一年之后你发现自己搭的策略跑不赢沪深300，这三万元一分钱都不会退给你。

更要命的是这道门槛的过滤方式：它筛掉的往往不是能力最差的人，而是预算最少的人。绝大多数人不是倒在策略不行，而是根本没走到"验证策略"那一步——他还在用免费行情软件手动抄数据的时候，就已经被这笔预付款劝退了。

张翼轸把这道门槛称作挡在普通人面前的第一道墙：数据接口是一堵，数据终端是另一堵，两堵墙叠在一起，把绝大多数人拦在门外。墙的高度不是由技术难度决定的，而是由价格标签决定的。

所以过去十几年的现实是：量化看起来离你很近——书店里每一本教材、券商每一篇研报、短视频里每一个讲"策略回测"的博主，都在讲这件事；实际上离你很远——你连第一步的数据都摸不到，所有的学习都停留在"看别人做"的层面。门槛的本质从来不是技术，而是成本结构。技术可以慢慢学，成本付不起就只能旁观。

这个格局，在 2026 年出现了肉眼可见的松动。

## 二、门正在塌：一场把入场券打成清仓价的比赛

松动发生在一个很多人还没注意到的场合：华泰柏瑞杯全国首届 ETF AI 交易巅峰赛。

先交代赛事本身。这是全国范围内的首届 ETF AI 交易比赛，参赛形态有三种：本人亲自上、用"AI涨乐"参赛、自带 Agent 参赛。三种形态对应三种人群——传统手动交易者、愿意用平台内置 AI 的普通用户，以及已经自己动手搭过智能体的进阶玩家。自带 Agent 参赛这个选项尤其值得注意：它等于官方承认了"你自己写的程序"是一个合法的参赛选手。

但真正值得展开的，是赛事背后的工具供给。赛事官方开放了 5 个 Skill：金融分析与咨询查询、金融指标与行情综合检索、自选股管理、A股模拟交易、条件选股。免费版每日调用 500 次，可申请进阶到每日 1000 次。

把这串数字翻译成大白话：过去一年 3 万元起步的数据接口，现在以每天 500 次的额度，以官方 Skill 的形式向参赛者免费开放。从 3 万/年到免费 500 次/日，这不是降价，是清仓——入场券的价格从"劝退级"直接打到了零门槛。

这 5 个 Skill 各管一段。金融分析与咨询查询和金融指标与行情综合检索，对应的是过去最贵的那部分：数据获取与初步分析；自选股管理和条件选股，对应的是研究过程中的资产管理与筛选；A股模拟交易，对应的是把想法变成可检验的动作。合在一起，恰好是一条完整的"数据→研究→验证"流水线——过去你需要花 3 万元买接口、再花几年时间自建的部分，现在被拆成了 5 个标准件，按次免费取用。

这里需要解释一下 Skill 是什么。它不是一款软件，而是装在 AI Agent 身上的标准能力包：检索行情是一个 Skill，管理自选股是一个 Skill，下单模拟交易也是一个 Skill。散户第一次可以像拼积木一样，把"数据获取、指标计算、模拟下单、条件选股"拼成一条属于自己的研究流水线，而不需要先租一整间机房、养一个开发团队。

赛事的激励机制也在传递同一个信号：比赛直接拿 Token 当奖金；对开源收益为正的 Skill，前 200 名各奖 100 元 Token 套餐。也就是说，这场赛事不只邀请你来用工具，还鼓励你把自己写的工具开源出来，让下一个人站上你的肩膀。Token 当奖金这个细节本身就说明了主办方对方向的判断：他们奖励的是"继续调用工具做研究的能力"，而不是一次性的名次。

有人会把这理解成一场营销活动。是的，它当然带营销属性，活动本身也未必长存，免费额度也完全可能随赛事结束而收紧——这一点后文还会再提。但要把"活动"和"工具形态"分开看：Skill 把数据与交易能力拆成标准件这件事，即使比赛落幕，它的方法论也会留下来。今天你用 5 个官方 Skill 拼流水线，明天同样的拼法可以换成任何其他来源的 Skill。重要的是"能力可以按次取用"这个形态已经跑通了，回不到从前了。

更重要的是，散户今天免费碰到的东西，三十年前是华尔街顶级机构的特权。

张翼轸在上述文章里交代了两件背景事实，值得原样转述。第一件：AI 辅助投资并不等于大模型辅助投资——量化基金用深度学习做量价因子，已经做了十几年，这是一条一直在暗处运转的成熟路线，只是普通投资者此前看不见、也够不着。你在新闻里看到的"量化巨头收益回撤"背后，是一整套早已工业化运转的机器学习流水线。

第二件：1993 年，西蒙斯把 Brown 和 Mercer 从 IBM 沃森研究中心挖到了文艺复兴科技公司。这两位是语音识别领域的顶级科学家，西蒙斯看中的正是他们的数学能力。这段挖角的底层逻辑是一句流传很广的话——预测市场和预测下一个音节，在数学上是一回事；语音识别和金融市场预测，用的是同一套数学。后来这两个人成了文艺复兴的二号、三号人物，这段历史在量化行业里人尽皆知。

把这两件事放在一起看：三十年前，要让"预测下一个音节"的人帮你预测市场，是大机构砸重金、开高薪、组团队才换来的组织能力，全世界拥有这种能力的机构一只手数得过来；三十年后，一个散户装上 5 个 Skill，每天就有 500 次免费调用的行情检索与模拟交易额度。这个对照没有夸张成分，两组数字都摆在明处：一边是 1993 年的重金挖角，一边是 2026 年的免费额度。

顺带说一句 Agent 本身的进化。尹John 在《Agent 自我改进的六条路》中把 Agent 的自我改进拆成了一个光谱：从最基础的提示词优化，到反思机制、记忆机制，再到更高层的进化式改进，分层已经相当成熟。这意味着 Agent 能做的事早已不止"查个行情"——它可以反思上一笔判断错在哪个环节，可以把教训写进记忆，在下一次遇到同类情形时自动提醒你避开。你今天装的不只是 5 个查询接口，而是一个具备反思与记忆能力的助手雏形。工具层的进化速度，比大多数人的感知要快。

但写到这里，必须先泼一盆冷水，而且这盆冷水比前面所有的甜头都重要：入场券便宜了，不等于能上岸。

工具平权解决的是"你能不能开始"，没有解决"你能不能活下来"。门开得越大，走进来的人越多，同一条路上的竞争密度只会更高，而市场本身的胜负结构，不会因为工具变便宜而变得更友好。历史上每一次散户工具的普及——从行情软件到智能条件单——都没有改变过盈亏分布的大结构，这一次大概率也不会例外。

所以这篇文章的后半部分，讲的不是免费工具怎么用，而是门后面的路上，新入场者最容易死在哪里。

## 三、门槛塌了之后，新入场者的三种典型死法

门票免费之后，最先发生的事情不是更多人选对了路，而是更多人以更快的速度撞上同样的墙。把新入场者折戟的方式归拢一下，大致是三种典型死法。这三种死法有一个共同前提：工具已经不再是瓶颈——恰恰是工具便宜了、上手快了、数据唾手可得了，这些死法才暴露得这么快。过去你要死，还得先攒够三万元；现在免费了，死亡的速度也提速了。

第一种死法：信息过载型。

免费接口每天给你 500 次调用额度，你用它检索行情、拉财务指标、跑条件选股，然后呢？你发现能看的东西多了，能信的东西没有变多。早盘刷宏观解读，午盘刷板块异动，收盘刷机构纪要，晚上再补一遍海外复盘——每一条信息单看都好像重要，合在一起却互相打架：这个说估值便宜，那个说景气下行；这个说资金持续流入，那个说主力暗中出逃。你每刷一轮，观点就动摇一次，持仓理由像天气一样一天三变。

信息过载的死法，不是死于信息太少，而是死于信息没有结构。每天 500 次额度给了你一万个观察点，你手里却没有一套规则决定哪些点值得看、看完之后对应什么动作。于是研究退化成刷屏，刷屏退化成焦虑，焦虑退化成频繁操作——而频繁操作在统计上几乎必然放大交易成本、压缩胜率。工具给了你无限的输入，却没有顺手给你过滤器；过滤器这一层，从来都要自己装。

第二种死法：情绪驱动型。

这种死法在行情热闹的时候最常见：涨的时候怕踏空，跌的时候怕套牢；持仓有浮盈拿不住，几天就想落袋；浮亏了不止损，安慰自己"拿久一点总会回来"。决策的触发器不是研究结论，而是当天的情绪温度。更隐蔽的变体是"研究替情绪打工"：你先因为看到别人晒收益而心动，再回头去找支持买入的研报和数据——研究不是为了得出结论，而是为了给已经做好的决定补一张批准单。

潇南在开源项目 WealthPilot 的实践记录里，把个人投资者的困境归纳为五条：资产分散在多个账户和平台、情绪驱动决策、信息过载、决策无法复盘、通用 AI 不了解"我"的具体情况。其中"情绪驱动决策"，是散户投资困境里最常见的一条。情绪驱动的麻烦在于它的隐蔽性：每次操作单看都有理由，连起来看才发现理由一直在漂移——买入时讲的是逻辑，拿不住时讲的是运气，离场时讲的是"就当交学费"。理由跟着行情涨跌变来变去，等于没有理由。

第三种死法：决策黑箱型。

这是三种死法里最安静、也最致命的一种：你赚过钱，也亏过钱，但无论赚亏，你都说不清当时为什么买、为什么卖、为什么是这个仓位、为什么是这一天。决策发生了，但决策没有留下任何记录，就像飞机失事后找不到飞行日志的黑箱。

黑箱型死法的后果是结构性的：你无法区分哪些钱是靠能力赚的、哪些钱是靠运气赚的；同样无法区分哪些亏损是系统性错误、哪些亏损是必要成本。于是同一个坑你会反复踩——不是因为你记性差，而是因为坑从来没有被记录下来，每一次踩坑对你来说都是"第一次"。更糟的是，人脑对赚亏的记忆是有选择性的：赚的单子记得特别清楚，亏的单子倾向于淡化，久而久之你对自己水平的自我评估会系统性偏高，然后在一个不经意的时刻，用远超自己真实水平的仓位去押一个自以为熟练的模式。

潇南对这一切有一句值得整段引用的论断：个人投资者缺的不是信息，而是把信息、资产、目标和纪律连起来的决策系统。这句话把三种死法收拢成了一个诊断：信息过载，是因为缺一套决定"看什么"的过滤系统；情绪驱动，是因为缺一套决定"何时动、动多少"的执行系统；决策黑箱，是因为缺一套决定"记什么、怎么复盘"的沉淀系统。三种死法，同一个病根——系统缺席。

还需要强调一点，潇南给自己的 WealthPilot 划定的边界非常清晰：它明确自己不是荐股软件、不是自动交易机器人，而是个人投资决策辅助工具。这个边界声明，值得每一个准备入场的人抄下来贴在屏幕旁边：任何工具——包括现在这些免费 Skill、包括市面上一切听起来很聪明的智能体——提供的是决策支持，不是决策替代。方向盘必须留在你自己手里，油门和刹车也是。

## 四、决策系统：普通人可以立刻动手的四步清单

诊断完死法，该给出路。"决策系统"听起来像机构里的名词，但它可以拆成四个普通人今天就能动手的动作，每一个都不花钱，每一个都只需要一点纪律。

第一步：用模拟盘跑通最小闭环。

华泰柏瑞这场赛事自带的 A股模拟交易 Skill，恰好是入场的第一块积木：它让你在零真金风险的环境下，把"数据→分析→模拟单→复盘"这条最小闭环完整跑通。注意关键词是"最小"——不是先搭一个完美系统再开始，而是先用最粗的流程跑一遍全链路：取一次数据，做一个判断，下一张模拟单，第二天回来对照结果。闭环的价值不在单次判断的准确率，而在于让你第一次拥有"完整的决策样本"——从输入到输出全程可追溯的样本。没有完整样本，任何复盘都是凭印象脑补。

具体到操作，第一周可以只做一件事：每天收盘后用行情检索 Skill 拉一次宽基 ETF 的量价数据，写下明天的判断和理由，第二天开盘用模拟交易 Skill 按判断执行，收盘后对照。一周下来你就有五个完整样本。样本不重要，流程才重要——你在练的是"决策可追溯"这个习惯，而不是练预测。

第二步：记账，把每一笔决策写成存档。

纪律的起点不是止损线，而是记账。具体做法：每一笔买卖（包括模拟单）写下四行字——买入或卖出的理由是什么；依据的是哪条数据；预期兑现的条件是什么；如果条件不兑现怎么办。事后对账，就能回答那个决策黑箱型死法里无法回答的问题：当时为什么这么做。

这一步呼应的正是潇南指出的痛点：决策没有沉淀，就无法复盘。文字存档看起来笨，但它是唯一能把"当时的你"和"复盘的你"分开的证据——行情会篡改记忆，白纸黑字不会。一个月后你翻自己的存档，大概率会发现两类惊人事实：一类是当时觉得理由充分、事后看完全站不住脚的决策；另一类是当时犹豫不决、事后看其实判断正确的决策。这两种事实，凭记忆你一个都发现不了。

第三步：把复盘交给 Agent，而不是交给情绪。

前面提到尹John 拆解的 Agent 自我改进光谱，反思机制和记忆机制都是已经成熟的层级。落到个人场景，你可以让 Agent 定期读你的决策存档，回答两个问题：这一类判断，我通常错在哪个环节？同样的错误，这个月出现了几次？让机器盯你的纪律，往往比你盯自己更可靠——情绪会撒谎，日志不会。

这一步的深层价值在于：你开始把"改进行为"外包给一个不知疲倦、不带情绪的第三方。人类复盘的最大敌人是自我保护——复盘会变成找借口大会；Agent 复盘没有面子问题，它只对比"你写的理由"和"实际发生的结果"，然后告诉你偏差在哪。

第四步：进阶之前，先认识一个坑。

如果你跑完模拟盘还想往深处走，从工具使用者升级为个人研究者，那么在搭建自己的因子数据库之前，先记住蝴蝶量化在《从0到1构建自己的个人因子数据库——实践方法与步骤》里强调的一个工程细节：财务数据必须用公告日（ann_date）对齐，而不是用报告期（end_date）对齐。原因在于：报告期截止的那一天，数据还没有公布，你的策略当时根本"看不见"它；如果回测时按报告期对齐数据，等于让策略提前偷看了未来。这就是量化研究里最常见的前视偏差，也是"回测漂亮、实盘翻车"的经典陷阱之一。

为什么专门讲这一个坑？因为它说明了免费 Skill 的真实边界：Skill 把门打开了，门里的路还是要自己一步步修。真正的量化研究里散布着大量类似的、不写在任何入门教程里的坑——数据对齐只是最著名的一个，还有幸存者偏差、未来函数、过拟合等等，每一个坑都可能让几个月的努力变成自我欺骗。免费的是入场券，不是通关攻略。
