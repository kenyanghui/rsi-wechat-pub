## 开篇

**先说两组数字。不评论。**

第一组，来自一份 2026 Q3 的量化岗位统计。

21 家公司。747 条在招岗位。

其中，软件工程 311 条。量化研究 78 条。

第二组，来自你最近一周的社交媒体。

四个字：量化没有未来。

这两件事同时为真，才值得写一篇长文。

**因为如果这个行业真的不要人了，它为什么还在招 311 个工程师？**

先别急着选边。这个问题有两个廉价答案。

廉价答案一：311 个工程岗说明行业在扩张。它省略了分母——311 是 747 的 42%，描述的是结构，不是增长。

廉价答案二：78 个研究岗说明研究已死。它省略了口径——78 条是“在招的、明确叫研究”的岗位，不是“所有做研究的人”。

**两个答案都跳过了同一件事：先把分母摆出来。**

本文只做这一件事。

不预测行业兴衰，不评价任何机构，不推荐任何岗位，也不构成求职建议或投资建议。

样本是 21 家海外/外资一线机构。中国内地私募不在其中。任何“国内量化也不招人”的推论都不成立。

所有数字来自媒体转述的岗位库统计，属二手口径，原始报告在文末标注。

本文只交付一件东西：一把尺子。

用来量你的“能力久期”。

## 一、先把分母摆出来

747 条 JD，按职能拆开，是这样一张表。

| 职能 | 条数（占比） |
| --- | --- |
| 软件工程 | 311（42%） |
| 其他 | 131（18%） |
| 量化研究 | 78（10%） |
| 量化交易 | 69（9%） |
| 其他职能 | 53（7%） |
| 机器学习 / AI | 44（6%） |
| 风险 / 运营 | 43（6%） |
| 数据 | 18（2%） |

如果把“核心量化岗”定义为研究 + 交易 + ML/AI，三者合计 191 条，占 26%。

再看资历。

实习 7%。

应届 / 初级 3%。

资深 / 管理 18%。

三个数都出自同一份 747 条样本。原文没有再对剩余份额做进一步拆分，所以这里只当结构信号读，不当精确分布用。

翻译一下。

这不是金字塔。金字塔底部宽、顶部尖，人可以从底部往上爬。

**这是一个哑铃。两头沉，中间细。**

一头是软件工程：311 条，42%，是职能分布里占比最高的一端。

另一头是“已经在场的人”：资深 / 管理 18%，再算上研究岗里 46% 要博士，配合 325 条标注年限的 JD（最低年限中位数 5 年），门槛明显偏向已经干完一轮长期训练的人。

中间是应届 / 初级：3%，细到几乎握不住。

78 条研究岗不在中间。它贴着这一头——那不是入口，是给已经完成长期训练的人准备的。

需要说明：这张图横轴是职能、纵轴是资历，是两个口径叠出来的示意图，不是单一分布。只当形状读，不当百分比读。

它说明这个行业不是不要人，是两头有位置，中间没有过渡带。

**入口在工程侧。腰部在收缩。有经验的一端在变贵。**

换句话说，如果你正站在哑铃外面往里看，你要挤的不是“研究”那一端，是“工程”那一端。

口径必须说清楚。枯燥，但省不掉。

第一，样本是 21 家海外/外资一线机构。QRT、WorldQuant、Jane Street、Point72、Citadel 这一类。中国内地私募不在样本内。所以这张表只能回答“全球一线机构想要什么”，不能回答“中国量化私募想要什么”。

第二，747 条里，明确标注 2026 Q3 发布的只有 292 条。另有 455 条在架但未标日期。所以“Q3 结构”是混合口径——它是一张“当下在架岗位”的快照，不是“Q3 新增岗位”的流量表。

第三，原文提到“LLM 进入量化 JD，占 6%”。这个 6% 的分母，原文没有完全交代。可以确定的只有：44 条 ML/AI 岗里约有一半要求 LLM，约 22 条，占 747 条的 2.9%。本文引用时一律写“原文口径 6%”，不做二次换算，也不把 2.9% 当成新结论。

第四，这是需求侧快照，不是薪资数据。岗位多不等于工资高。这一点第二节展开。

第五，全部数字为二手口径，来自媒体对岗位库的转述。原始报告链接在文末。

接受这五条约束之后，这张表才可用。

## 二、把技能当因子读

做量化的人看一张技能清单，第一反应不该是“我要学哪个”，而是“这个变量的覆盖率是多少”。

这里借三个概念。先说清楚借的是什么，再说清楚借到哪儿为止。

**概念一：覆盖率，对应因子研究里的 IC。**

IC 是信息系数，衡量因子对未来收益的预测能力。覆盖率是另一个维度：这个因子在多少标的上有效。

放到 JD 上，“出现率”就是覆盖率——多少比例的岗位明确要求它。

但出现率高只说明“需要”，不说明“稀缺”。

**概念二：拥挤度。**

一个因子被发现、被发表、被所有人使用之后，超额收益会被交易掉。这叫因子拥挤。

技能同理。

一项技能出现率高、学习路径清晰、教程满天飞，它的供给也会跟着涨。供给涨得比需求快，单价就往下走。

所以“出现率高”和“值钱”之间，隔着一个拥挤度。

**概念三：久期与折旧率。**

久期原本是债券概念，衡量现金流的平均回收时间。久期越长，价格对利率变化越敏感。

借到能力上：这项能力还能给你产生多少年的“报价能力”。

折旧率则是它每年失效的速度。

三个概念摆好，可以读表了。

先看全样本的硬技能出现率。

Python 53%。

风险管理 25%。

C++ 23%。

Linux / Unix 22%。

分布式 / 并发 19%。

Python 过半，是这张表里覆盖率排第一的技能。

但如果你只看核心量化岗（研究 + 交易 + ML/AI），Python 的出现率是 72%。

核心岗收敛之后，画像变成这样：

Python 72%。

ML / DL 39%。

统计 / 概率 38%。

C++ 37%。

PhD 27%。

算法 / 数据结构 26%。

72% 这个数字，很多人会读成“Python 很重要，快去学”。

正确的读法几乎是反过来的：72% 意味着几乎所有岗位都要，也意味着几乎所有候选人都得会。

一项人人都会的技能，不会给你溢价。它只是入场券。

入场券的作用是让你不被筛掉，不是让你被加价。

真正的溢价在哪？

看稀缺项。

KDB+/q：3 条。

DPDK / 内核旁路：3 条。

FIX 协议：5 条。

强化学习：4 条。

JAX：4 条。

Go：6 条。

这些数字小到可以忽略，但它们出现在“必须有”的 JD 里。

一句话：这是一批覆盖率极低、但一旦缺了岗位就招不到人的技能。

**低覆盖，高必需。**

这就是定价权所在的位置。

举个具体的。KDB+/q 是高频交易里的事实标准时序数据库。要求它的那 3 个岗位，如果候选人不会 q，岗位就是空缺。

它没法被“再学两周 Python”替代。

所以它贵。但它也窄——离开高频交易场景，q 的迁移价值迅速下降。这一点第四节重点讲。

再看 LLM。

原文口径 6%。44 条 ML/AI 岗里约一半要求 LLM。

这是这张表里刚冒头的一个变量。

新因子的特点是：IC 未知，衰减未知。

它可能是 alpha——AI 原生投研刚刚开始，会用它的人少，能把它接进生产流程的人更少。

它也可能是噪音——两年后 LLM 变成和 Python 一样的入场券，出现率冲上 60%，溢价归零。

现在没人知道。包括写 JD 的人。

所以对 LLM 的正确态度不是“押注”，是“低成本试仓”：小代价获得暴露，不押上身家。

再看分方向的能力画像。三条路径，三种人。

| 方向 | 最高频要求 |
| --- | --- |
| 量化研究（78 条） | Python 87%、统计/概率 62%、C++ 54%、ML/DL 53%、PhD 46% |
| 量化交易（69 条） | Python 58%、风险管理 38%、期权/衍生品 32% |
| ML / AI（44 条） | Python 68%、LLM 50%、PyTorch 32% |

研究岗：PhD 46%。学历在这里是硬门槛，接近一半的岗位明确要求博士。

交易岗：风险管理 38%，期权/衍生品 32%。这是产品与风险的语言，不是论文的语言。

ML/AI 岗：LLM 50%，PyTorch 32%。这是工程的语言，且明显偏向“能把模型跑起来”，而不是“能推导模型”。

换句话说，“量化”不是一个岗位，是三条能力栈完全不同的赛道。用同一份学习计划去打三条赛道，是高频出现的浪费。

最后看门槛的稀释。

PhD 86 条，占 12%。

顶级院校 28 条，占 4%。

论文 / 发表 16 条，占 2%。

奥赛 / 竞赛 5 条，占 1%。

CFA / FRM 7 条，占 1%。

12% 的 PhD 占比，会让两类人同时误判。

一类人想：博士才 12%，说明学历不重要。错。学历不重要是全局结论，对研究岗不成立——研究岗 46%。

另一类人想：必须读博。也错。绝大多数岗位不要求博士。

正确的读法是：学历是分赛道的入场券，不是全行业的通行证。

这一段落的量化味结论只有一句：

你要找的不是“看起来重要”的变量，是“别人没法替代、而系统必须有”的变量。

这跟选因子是同一个动作。

IC 高不等于能赚钱。覆盖率不等于有溢价。

> **稀缺乘以必需，才等于定价权。**

## 三、为什么是腰部在塌

上一节说，哑铃的中间是细的。

这一节解释为什么细。

市面上关于“量化没有职业未来”的解释，大致有四条。四条都有道理，但都需要校准。

**解释一：因子生命周期被压缩。**

原文的说法是，因子被压缩到“毫秒级被榨干”。

这个说法只对了一半。被压缩的确实是因子的有效窗口，但压缩只发生在一条特定链条上，而它有入口条件。

链条四步。

第一步，数据公开。行情、财报、持仓、订单簿，获取成本在持续下降。过去要花钱买的字段，现在很多有免费替代。

第二步，复现成本下降。一篇论文从“看懂”到“跑出同样的曲线”，所需工程量在缩小：算力便宜了，框架成熟了，代码模板到处都是。

第三步，拥挤速度加快。一个因子发表之后被市场吸收的时间在缩短——从“有人做出来”到“很多人都做出来”，间隔越来越短。

第四步，同质化因子衰减。同一组信号被越来越多的资金交易，超额收益被提前吃掉。“毫秒级被榨干”的真实含义不是因子本身变弱，是抢它的人来得太快。

这条链条的起点，是“一个已经公开的结论”。

所以它只打击一种研究：复现型研究。

复现型研究的输入是别人的问题，输出是同一组信号。它天然依赖公开信息，也就天然被这条链条约束。别人复现得越快，它的窗口越短。

问题定义型研究不吃这一刀。

它的输入不是论文，是自己对市场结构的判断：谁在被规则逼着交易、哪个约束还没被定价、哪种摩擦正在变大。这类问题的答案不在公开文献里，复现成本下降对它没有加速作用。

它慢，不是因为信息慢，是因为验证慢——要等足够多的样本，要等一次真实的环境变化。

一句话：复现型研究的天敌是“别人也能复现”；问题定义型研究的天敌是“这个问题根本不存在”。前者会被 AI 加速杀死，后者只能被现实证伪。

这条线，第四节还会以“工具型 / 系统型”的名字出现。

**解释二：LLM 清洗初级研究员。**

这一条成立，但要看清洗的是哪一段。

被清洗的是“洗数据、跑回测、调包”这一段。

而这一段，恰好对应 JD 里几乎消失的入门岗。

应届 / 初级只占 3%。

这两件事放在一起，是一件很硬的事：市场上明确为“刚入行的执行型研究”准备的岗位，只有 3%。

不是“公司不愿意培养新人”。是这一段产出已经可以被工具批量完成，没必要单独设岗。

**解释三：监管收紧，高频灰色红利消失。**

范围要收窄：被压的是高频里的灰色部分，不是全部量化。

对国内读者要小心：本文样本是海外机构，监管环境不同，不能直接搬。

**解释四：行业拥挤，军备竞赛。**

表现为“投入几亿只为维持不掉队”。

注意结构：投入几亿，目标不是“赚更多”，是“不掉队”。

这是负和竞争——所有人的成本都在上升，相对位置不变。

四条校准完，可以收一句。

> **塌陷的是“可被流程化”的那一段，不是整个行业。**

这个结论有一个直接推论：如果你正在学的，正好是“可被流程化”的那一段，你会感到整个行业在消失。

但消失的不是行业。是你站的那一格。

再补一条尾部风险提示。

有一篇劝退文里说，量化是“最顶尖 1% 拿走 99% 的财富与关注”，性质类似电子竞技。

这是定性判断，不是数据。本文不拿它当论据。

但它作为风险提示是有效的。

因为如果这个描述哪怕只有一半成立，那么“平均数”就是格外危险的参考系。

平均数会把 1% 的收益摊到 100% 的人头上，让你以为中位数也在上涨。

更可能的真相是：头部极贵，腰部极薄，尾部极长。

这不是一个“努力就有回报”的分布。

在这个分布里做决策，你要问的不是“我能不能成为前 10%”，而是“如果我落在中位数，我还活得下去吗”。

这个问题，下一节给工具。

## 四、久期、凸性、集中度

这一节是全文的重心。

前面三节都在讲市场。这一节讲你。

方法很直接：把你的人力资本，当成一个持仓来管。

任何持仓都有三个维度：能持多久、跌了能不能换、押得有多重。

对应到能力上，就是久期、凸性、集中度。

### 4.1 久期：这项能力还能报价几年

先定义清楚。

久期不是“这项技能难不难”，也不是“现在工资高不高”。

久期是：**这项能力在未来还能持续产生“有人愿意付钱”的年数。**

注意措辞是“付钱”，不是“有用”。

有用但不付钱的能力，久期是零。

按这个定义，能力可以粗分成两类。

**工具型技能**：会用某个库、某个平台、某个接口、某套报表。

久期 1–2 年。

理由很直接：工具会换代。API 会改，库会停止维护，界面会重做。你对具体工具的熟练度，会随工具一起折旧。

**系统型能力**：把研究流程工程化，把模糊判断拆成可验证规则，把一次性结论变成可复用资产。

久期 5–10 年。

理由也很直接：这类能力不绑定具体工具。换语言、换平台、换市场，内核还在。

这里要说清楚借用在哪里失效。

债券的久期越长，对利率越敏感，风险越大。

能力上不完全一样。

能力久期长，不代表更危险，而代表定价权更依赖“未来是否仍然必需”这个判断。

工具型技能的风险在“当下供需”——今天有人要，明天可能没人要，你立刻能感受到。

系统型能力的风险在“未来判断”——它可能五年有效，第六年被一个新范式整体绕过，而你在这五年里毫无痛感。

所以久期长不是安全。

**它是风险换了一种形态：从“高频小波动”换成“低频大回撤”。**

很多人愿意学“看起来更长期”的东西，是因为以为长期等于安全。

不是。长期只是把结算日推后了。

那怎么用久期做决策？

一条简单的规则：

**久期短的技能，必须高频变现。**

**久期长的能力，才配得上延迟变现。**

落到实处。

如果你的核心能力是“会用某套工具”，你不能等。你要接活、按次收费、尽快把它换成现金流，因为它的报价窗口正在关闭。

如果你的核心能力是“能把研究做成系统”，你可以等。你可以做产品、做自营、做资产，因为它的报价窗口还长。

用短期能力去做长期的事，是高频出现的错配——你在一件需要三年才能验证的事情上，用一项两年就过期的能力去支撑。

撑不到验证那天。

### 4.2 凸性：贬值之后，它还剩下什么

凸性原本描述价格对变化的非线性响应。

借到能力上，只问一个问题：

**当环境剧变，这项能力的残余价值是多少？**

两种形态。

**线性能力**：只会一个动作。环境变了，价值直接归零。曲线是一条直线，撞到零就停在那里。

**凸性能力**：有一个可迁移的内核。环境变了，外壳脱落，内核还在，还能在新环境里重新长出外壳。

举两个真实对照。

Python：高凸性。

它的价值不在语法，在“能把想法变成可运行程序”这个内核。换成数据分析、换成后端、换成自动化，这个内核都能迁。

所以 Python 出现率高（53%），但它的凸性也高。这两个属性不冲突——它同时是“拥挤的”和“可迁移的”。

KDB+/q：低凸性。

它在高频交易里是事实标准，单价极高。但离开这个场景，迁移价值迅速衰减。

所以它贵，但它是“高单价、低流动性”，不是“高安全”。

这个区分值钱。

很多人把“稀缺”直接等同于“安全”。不是。

稀缺分两种。

一种是“稀缺且可迁移”——比如能把复杂系统讲清楚的能力。这种稀缺是护城河。

一种是“稀缺且不可迁移”——比如只会某一个垂直系统。这种稀缺是抵押品，不是护城河。

**抵押品的特点是：你只能把它押给一个人。押错了，就没有第二次。**

所以看到稀缺技能，先别问“它值多少钱”，先问“它还能押给谁”。

只能押给一个人的技能，定价权在对方手里。

### 4.3 集中度：你是不是 100% 单票重仓

第三个维度经常被忽略。

绝大多数人的人力资本配置是这样的：

100% 押在一个行业。

100% 押在一个职能。

没有对冲。

不可分割——你不能把“我的三年经验”拆成十份，卖十次。

直接后果是：

**行业的波动，对机构是配置问题，对你是生存问题。**

机构可以在组合里调权重。你不能。

机构可以在行业间轮动。你不能。

机构错了，是回撤。你错了，是断供。

这不是危言耸听。这是杠杆结构的差异——你的收入曲线和这个行业的相关性是 1.0，而且没有第二个来源。

那怎么办？

降集中度有三条路，成本依次上升。

第一条，加一条不相关的收入来源。成本最低，见效慢。

第二条，把能力改造成可迁移的形态。最根本，因为它同时降久期风险和集中度风险。

第三条，换赛道。成本最高，且不可逆。

三条路的共同点是：都要在你还没被迫做的时候做。

等行业的岗位结构已经变了再动，你动的不是配置，是止损。

### 4.4 三层杠杆：为什么只有第三层允许你“卖很多次”

纳瓦尔把杠杆分成三层：劳动力、资本、零边际成本复制（代码、媒体、产品）。

三层有递进关系，很多人忽略。

**劳动力杠杆**：你要管人。管人的前提是有人愿意被你管，也就是你先得有个位置。

**资本杠杆**：你要有本金。本金的前提是你先有存量。

**零边际成本复制**：你要有可复制的产物。产物可以是代码、是内容、是产品、是一套流程。

前两层的前提都是：你得先“有”。

第三层不一样。它的前提是“你能做出来”。

所以它对没有存量的人更重要——它是唯一一个不要求你先有位置的杠杆。

而它的门票，不是聪明。

是把能力做成系统。

一个判断，只卖一次，是工资。

一个判断，做成流程，卖很多次，是产品。

一个判断，做成资产，让别人替你复用，是生意。

三者的差别不在判断的质量，在封装的程度。

必须给风险提示。

自营和产品的失败率，远高于就业。

**杠杆放大的是结果，不是能力。**

一个没有 alpha 的策略，加上杠杆，只是更快地亏完。

一个没有验证过的判断，做成产品，只是更快地被市场否定。

第三层杠杆的门票是“把能力做成系统”，但这张票不保证你能进场。

它只保证你有资格排队。

## 五、三问体检，和一个 7 天动作

前四节都在讲结构。这一节给工具。

三个问题，现在就可以问。

### 第一问：半衰期

写下你最贵的三项能力。

逐项问一句：

**如果明天出一个新模型、新平台、新范式，这项能力还剩多少？**

不要给模糊答案。给一个数字：剩 80%、剩 50%、剩 10%。

方法粗暴但有效。目的不是精确，是逼你承认某一项可能只剩 10%。

大多数人写完之后会发现：三项里有两项，半衰期不到两年。

这就是你要处理的真实仓位。

### 第二问：可迁移性

同一项能力，换一个行业、换一个场景，还能不能用？

能，它是资产。

不能，它是抵押品。

抵押品不是坏东西。它单价高，能让你在特定场景拿到好报价。

但不能把它当护城河。

**护城河的定义是“别人进不来”。**

抵押品的定义是“你出不去”。

这两个东西长得很像，作用完全相反。

### 第三问：市场 IC

过去 12 个月，有没有人为这项能力单独付过钱？

注意限定词：单独。

不是工资。工资是打包价，它同时买了你的时间、你的服从、你的在场。

单独付钱指的是：一个项目、一次咨询、一份交付物、一个产品，有人为“这项能力本身”结了账。

这里要补一句边界。IC 在因子研究里是因子值与未来收益的相关系数，是一个能算出来的统计量。本节借这个词，只借“被独立定价”这一层意思。严格说，这里的市场 IC 是支付意愿验证，不是统计量——它由账单证明，不由回归算出。

如果没有，说明这项能力还没有市场 IC。

没有市场 IC 的能力，不代表没价值。

它代表价值还没有被独立验证过。

而所有“延迟变现”的路径——产品、自营、资产——都要求先有市场 IC。

因为延迟变现的本质，是把今天验证过的东西，推到明天去收钱。

没验证过的东西，推不到明天。

### 抗折旧三件套

三个问题问完，给三个动作。

**一、把重复流程写成系统。**

降低边际成本。同一件事做第二遍，不该再从零开始。

**二、把判断写成可验证规则。**

提高可交付性。说不清楚的判断只能自己用；写成规则，才能交给别人执行，也才能被证伪。

**三、把结果做成可复用资产。**

提高复用率。报告、代码、模板、失败记录都是资产。

尤其是失败记录。它是成本极低的经验，也经常被丢掉。

三件事都不难。难在它们都不紧急。

不紧急的事，只有在你还不需要它的时候做，才有意义。

### 7 天动作

最后给一个具体动作。

选一项你认为最贵的能力。

写成一份 3 页的 SOP。

发给 5 个潜在付费方。

只记录一件事：有没有人愿意为它单独付钱。

不记录夸奖。

夸奖是成本最低的信息。它让你感觉良好，但不改变定价。

有人付钱，哪怕只有一个人、哪怕金额很小，这是一个信号：这项能力有市场 IC。

没人付钱，也是一个信号：你评估的“最贵”，可能只是“最难”。

**难度和价格，是两件事。**

回到那个动作。设想一个人：做了三年因子，把最得意的一套流程写成 SOP，发出去 5 份，0 回复。这个结果不说明他的能力不值钱，只说明“有人愿意付钱”这件事，他还没验证过。

## 写在最后

回到开头那两组数字。

311 比 78。

4 比 1。

> **市场从来不是在给“努力”报价。**
>
> **它在给“稀缺且必需”报价。**

AI 没有让能力消失。

它让“可被流程化”的能力加速贬值，让“能把能力做成系统的人”变贵。

对只能执行单点动作的人，是坏消息。

对能把判断封装成系统的人，是好消息。

对还没进场的人，是一条需要重新计算的路。

本文没有告诉你该学什么。

它只给了一把尺子：久期、凸性、集中度，加一个市场 IC。

四把尺子量完，你会知道自己站在哑铃的哪一端。

最后留一个问题。

如果明天你的能力要重新定一次价，你会把它挂在哪个格子里？
