# 「一句话生成量化策略」爆火后，我拆了它的源码——最 vibe 的工具，干着最反 vibe 的事

> 港大 HKUDS 开源 Vibe-Trading 源码拆解：门槛塌进一句对话，纪律焊死在代码契约；影子账户第一次把「你自己」放进回测

## 一、量化也有了「一句话生成」

2026 年如果你关注 AI 编程，「Vibe Coding」不陌生：对着编辑器说一句话，AI 把 App 生成出来。现在这套体验被搬进了量化交易。

港大数据智能实验室 HKUDS（LightRAG 背后的团队）在 2026 年 4 月开源了 Vibe-Trading，5 月上架 PyPI，安装是一条命令：pip install vibe-trading-ai。装完之后用自然语言描述想法——比如「测一下低波动异象在 A 股近五年是否成立」——它会自己走完整条链路：写策略代码、拉行情与财务数据、跑回测、生成带图表的研究报告。项目在 GitHub 趋势榜挂过热门，全网讨论几乎都落在同一句话上：量化门槛从「会写 Python」降到了「会说话」。

但这个叙事只讲了一半。我把源码翻了一遍（基于 commit 3a752d5），结论恰恰相反：**这个项目最 vibe 的是外壳，最反 vibe 的全在里子。**爆火的从来不是那 462 条公式，而是它把「纪律」焊死在了代码契约里。下面按顺序拆。

## 二、四大件：一个研究台的标配

先过一遍它交到桌面的东西，四个数字：74、29、6、6。

**74 个金融技能，且自进化。**技能是最小能力单元，覆盖因子构造、回测、数据清洗、风险分析等八大类。关键设计是自进化：对话里跑通一条完整流程，系统自动把它固化成新技能（save_skill），不好用就 patch_skill、delete_skill。研究经验第一次变成可版本管理的资产，而不是散落在聊天记录里的上下文。

**29 个 Swarm 多 Agent 团队。**单个 agent 容易一本正经地胡说，它把研究任务拆成团队。最典型的是「投资委员会」：多头分析师、空头分析师先各自拉真实数据再进场辩论，风控官挑刺，PM 汇总裁决——观点对冲发生在输出之前，而不是之后。

**6 个市场的独立回测引擎。**A 股的 T+1、涨跌停、财报披露时点，与美股、加密完全是三套规则。它没有用一个通用引擎糊弄所有市场，而是每个市场一套独立引擎，A 股引擎专门做了 PIT（point-in-time）财报处理，防止用「未来才披露的数据」回测「过去的市场」。

**6 个数据源**：Tushare、AKShare、yfinance、OKX、CCXT、Futu，覆盖 A 股、加密与港美股券商；另有五层上下文压缩，保证长链路研究不撑爆模型记忆窗口。

到这里，它还是一个「体验很好的一句话研究台」。真正值得写的，在源码里。

## 三、反转：一句话生成的是候选，不是 alpha

**先说一个冷知识：这 462 条因子公式，本身一文不值。**按仓库自述口径，项目受版本控制的文件有 482 个，其中重实现了约 462 条公开因子公式，来源五家：qlib158、WorldQuant alpha101、国泰君安 gtja191，加 academic 与 fundamental 两个学术与基本面合集。这些公式全是公开数学——alpha101 十年前就躺在论文附录里，任何研究员都能抄。如果爆火的理由是「462 条公式随便用」，这个理由不成立：公式在哪都免费。

值钱的是另一件事：让四百多个因子文件在同一套契约下互不干扰跑完一轮、坏文件不拖崩整轮、坏信号不伪装成好信号混进统计。它把这件事拆成了四道写死在代码里的纪律契约：

**契约一：NaN 一律传播，禁止静默补零。**不少自研框架遇到数据缺失直接 fillna(0)：停牌成交量为零、财报缺失填零，坏数据摇身变成「真实数据」，混进均值与相关性计算。Vibe-Trading 的算子层规定：输入有 NaN，输出就带 NaN——缺失必须一路可见地传播、在统计口径里暴露，而不是被悄悄洗白。坏信号可以存在，不许化妆。

**契约二：delta(d≥1)，偷看未来在 API 层「写不出来」。**因子常用差分算子 delta(x, d)：今天减 d 天前。若允许 d≤0，等于用未来数据算过去的信号——回测里最经典的作弊。它的 lookahead ban 做在算子签名上：d 最小取 1，零与负数在参数校验层直接报错。不是「提醒研究员别作弊」，而是让作弊那行代码根本写不出来。纪律从文档层下沉到了类型层。

**契约三：输出强制体检，NaN>95% 判失败。**因子算完不许直接入库，先过体检：输出形状与输入一致、无 ±inf、NaN 占比超 95% 判死。这条规则杀死的是「看起来跑通了、实际没算出东西」的僵尸因子——它们最危险，因为不体检的话，会安静躺在因子库里等人调用。

**契约四：SkipAlpha 与 RegistryError 分开记账。**一轮批量跑下来，有的因子被跳过（skip），有的因子报错（error）。混在一起记账的后果是：你永远分不清「这个因子是本就不该跑（条件不满足）」还是「它坏了（代码有 bug）」。两者分成独立计数器——「主动放弃」是过滤在工作，「意外故障」是需要修的债，这是完全不同的两种信号。

**再加一刀：strict 模式做同宇宙随机对照。**「跑赢基准」不稀奇——上千只股票的宇宙里随机选一组，大概率也有正超额。strict 模式把候选因子与同一宇宙的随机对照放在一起比：判别力不显著优于随机、只跟零比有正收益的，照样不合格。这一刀砍掉的是大部分「回测里像 alpha、实盘里是噪声」的产物。

拆解时印象最深的是一句判断：**「公式是公开的数学，难的是让四百多个文件在同一套契约下互不干扰跑完一轮，坏文件不能拖崩整轮。」**——这句判断出自奇连 AI 对该项目 commit 3a752d5 的源码拆解。它基本回答了「AI 时代量化研究员还值不值钱」——AI 可以 vibe 出一万个候选，但分辨哪个是 alpha、哪个是幻觉，靠的恰恰是这些一点也不 vibe 的契约。

## 四、Shadow Account：量化第一次回测「你自己」

中金的 Loop 引擎在用循环自动「生产因子」，QuantML 把 AI-Native 框架叫「研究操作系统」——而 Vibe-Trading 往前多走一步：研究台交给对话之外，连「你自己」都成了被回测的对象。

这个功能叫 Shadow Account（影子账户），全网几乎没有拆解过它的机制。流程六步：

1. 上传券商交割单；
2. 解析每一笔交易行为；
3. 构建行为画像——你在什么行情买入、拿多久、什么条件下卖出；
4. 从行为里提取一条「影子策略」：假如有个机器人完全按你的习惯操作，它长什么样；
5. 把影子策略放回历史行情回测；
6. 输出审计报告，核心问题只有一个：**「严格按影子策略操作能赚多少 vs 你实际赚了多少。」**

差价从哪来？按四种常见偏见归因：

- **处置效应**：盈利仓拿不住、亏损仓舍不得砍——提前收割利润，同时放任亏损扩大；
- **过度交易**：手续费与滑点一笔笔磨掉收益，交易频率本身成了一项负贡献；
- **追涨杀跌**：买在情绪高点、卖在恐慌低点，你稳定地在最贵的时刻行动；
- **锚定效应**：死守成本价——市场不关心你的成本是 12 还是 15，但你所有买卖决策都围着它转。

要说明白一个字：这套诊断是**启发式规则**，不是严格统计检验——它给你的是一张「行为体检报告」，不是论文级因果推断。但即便是启发式，它也回答了一个过去只能靠感觉回答的问题：**「你本可以赚多少 vs 实际赚了多少，差价就是你情绪的账单。」**量化行业回测了五十年的策略，第一次有人把「策略之外的那个变量」——交易者本人——也放进了回测。

## 五、落点：领走的不是一只龙虾，是一条带纪律的生产线

为什么普通人值得花一个下午研究它？MIT 协议开源，意味着你领走的不是一只「会用就还回去」的工具，而是一条能搬回家改造的生产线——源码、契约、技能体系全部可读可改。

纳瓦尔说过，普通人够得着的杠杆只有代码和媒体，因为它们的复制成本约等于零；资本与劳动力杠杆需要先有信用和人脉，不属于起步阶段。而 builder 的定义不是「创业」，是「让系统脱离你自动运转」。

按这个标准，路径可以拆得很具体，用「学、造、连」三个循环走：

- **学**：把四道纪律契约当免费教材读。NaN 传播、lookahead ban、输出体检、分开记账，这四条规则在任何自研回测框架里都成立，读透一个开源项目的源码，抵得上十篇泛泛而谈的「量化工程最佳实践」。
- **造**：跑自己的因子动物园。462 条公开公式是脚手架，真正属于你的资产，是把四条契约抄进自己 checklist 之后产出与验证的那部分。一篇讲 builder 的文章举过一个例子：有人把简历优化做成 18 个模板加 246 条话术的系统，做到月入三万——注意，这是个案、不是普遍规律，但路径是成立的：先有系统，再上杠杆，最后才是收入。
- **连**：先拿 Shadow Account 审计自己的交割单。这是成本最低的起点——不写一行代码，就能拿到第一份「偏见让你少赚了多少」的量化答案。

财富自由在这个语境里不是口号，而是一条可拆解的路径：把带纪律的开源系统搬回家，学它的契约，造自己的验证流程，连上你的真实数据。系统的纪律性每提高一分，你对自己操作的信任就多一分——这比任何口号都更接近投资的真相。

## 风险提示（请务必读完）

收尾之前，这段必须单独成段：Vibe-Trading 是 2026 年 4 月才开源的年轻项目，社区与生态尚在早期，接口与行为都可能变动；其回测引擎的严谨性——尤其 A 股 T+1、涨跌停与 PIT 财报处理——请在自己的数据上独立验证，不要默认「开源=严谨」；Swarm 多 Agent 的输出质量依赖底层大模型的工具调用能力，同一问题不同模型、不同轮次可能给出不同结论；Shadow Account 的偏见诊断是启发式规则而非严格统计检验，结论请当参考而非定论；历史回测不代表未来表现，样本内表现优异的策略实盘可能失效；本文对开源项目的拆解仅为工程分析与研究参考，AI 生成的策略不构成任何投资建议；项目含境外数据源（yfinance、OKX、CCXT、Futu 等），自部署使用时请自行确认数据获取与使用的合规性。市场有风险，任何决策请独立判断、自担结果。

## 写在最后

门槛塌了是真的：会说话就能跑一轮回测。但读完源码你会发现，这个项目真正的贡献恰恰在反方向——它没有让量化变得更随意，而是给「随意」这件事的每一扇门都焊上了栏杆。

工具越 vibe，纪律越贵。这句话，送给所有想用 AI 做研究的人。
